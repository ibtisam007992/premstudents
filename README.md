# استمارة استئذان الطالبات — نسخة GitHub Pages

هذه نسخة ثابتة (Static HTML) من الاستمارة، لرفعها على GitHub واستضافتها عبر
GitHub Pages. بخلاف نسخة Claude الأصلية، هذه النسخة تتصل مباشرة بجوجل شيت
الخاص بك عبر "Google Apps Script" بدلاً من مزايا Claude.

## ما الذي تغيّر عن نسخة Claude؟

| الميزة | نسخة Claude (Artifact) | هذه النسخة (GitHub) |
|---|---|---|
| حفظ الاستئذان | قاعدة بيانات داخلية + مزامنة تُنشئ ملف شيت جديد | **يُضاف كصف جديد مباشرة** في نفس جوجل شيت (أفضل فعلياً — لا تكرار ملفات) |
| بحث اسم الطالبة | عبر اتصال Google Drive الخاص بحسابك | عبر قراءة عامة (CSV) من شيت الطالبات |
| قراءة رقم البطاقة بالكاميرا | تلقائية بالذكاء الاصطناعي (داخل متصفح الزائرة فقط) | تلقائية أيضاً، لكن عبر رفع الصورة مؤقتاً إلى درايف المدرسة واستخدام OCR المجاني فيه (التفاصيل والخصوصية أدناه) |
| تحديث السجل والعداد | لحظي (realtime) | عبر تحديث تلقائي كل 45 ثانية + زر "تحديث الآن" |

## خطوات الإعداد (مرة واحدة فقط)

### 1. إنشاء جوجل شيت لحفظ السجلات
- أنشئي جوجل شيت جديد فارغ، وسمّيه مثلاً **"قاعدة استئذان الطالبات"**.
- لا حاجة لإضافة أعمدة يدوياً — الكود سينشئها تلقائياً عند أول حفظ.

### 2. ربط الشيت بكود Apps Script
- من داخل الشيت: **الإضافات (Extensions) ← Apps Script**.
- احذفي أي كود تجريبي موجود، والصقي **محتوى ملف `Code.gs`** المرفق هنا كاملاً.
- غيّري السطر:
  ```
  var SHARED_TOKEN = "change-this-secret";
  ```
  إلى كلمة سرية من اختيارك (أحرف وأرقام، بدون مسافات)، واحتفظي بها جانباً.
- احفظي المشروع (Ctrl+S).

### 3. تفعيل خدمة Drive API (لازمة لقراءة البطاقة تلقائياً)
- من الشريط الجانبي الأيسر في محرر Apps Script اضغطي على **+** بجانب **Services**.
- اختاري **Drive API** من القائمة، ثم اضغطي **Add**.
- إن تخطيتِ هذه الخطوة ستبقى بقية الاستمارة تعمل بشكل طبيعي، لكن قراءة رقم
  البطاقة تلقائياً بالكاميرا لن تعمل (ستظهر رسالة خطأ عند التصوير).

### 4. نشر الكود كـ "Web App"
- من الأعلى، اضغطي **Deploy ← New deployment**.
- اضغطي على أيقونة الترس ⚙️ واختاري النوع **Web app**.
- اضبطي:
  - **Execute as:** Me (حسابك)
  - **Who has access:** Anyone
- اضغطي **Deploy**، وقد يطلب منك الموافقة على الصلاحيات (Authorize) — وافقي،
  وستلاحظين الآن طلب صلاحية إضافية للوصول إلى Google Drive (بسبب خطوة 3)،
  وهذا متوقّع.
- بعد النشر سيظهر لك رابط باسم **Web app URL** — انسخيه، شكله مشابه لـ:
  `https://script.google.com/macros/s/XXXXXXXXXXXX/exec`

> **إذا كان لديك نشر سابق من نسخة أقدم من `Code.gs`** (أي أنك فعّلتِ
> الاستمارة قبل إضافة ميزة القراءة التلقائية): لا تُنشئي نشراً جديداً من
> الصفر، بل من **Deploy ← Manage deployments** اضغطي أيقونة التعديل (✏️)
> بجانب النشر القائم، واختاري **Version: New version** ثم **Deploy**.
> بهذا يبقى نفس رابط Web app URL كما هو (لا داعي لتغييره في `index.html`)،
> ويُحدَّث فقط الكود الذي يعمل خلفه ليشمل ميزة القراءة التلقائية.

### 5. مشاركة شيت أسماء الطالبات للقراءة العامة
شيت أسماء الطالبات (نفس الشيت المستخدم سابقاً في نسخة Claude) يجب أن يكون
قابلاً للقراءة العامة حتى تعمل خانة البحث في الصفحة الثابتة:
- افتحي شيت الطالبات ← **مشاركة (Share)**.
- غيّري الإعداد إلى: **"أي شخص لديه الرابط" ← "مُشاهد (Viewer)"**.
- لاحظي: هذا يعني أن أي شخص يملك رابط هذا الشيت تحديداً يمكنه رؤية أسماء
  الطالبات وصفوفهن (دون أرقام بطاقات أو هواتف، لأن تلك غير موجودة في هذا
  الشيت أصلاً حسب تصميمه الحالي).

### 6. تعديل الإعدادات داخل `index.html`
افتحي ملف `index.html` بأي محرر نصوص، وابحثي عن السطر `var CONFIG = {` ثم عدّلي:

```js
var CONFIG = {
  ROSTER_SHEET_ID: "1HQONakQiL1_0YXpBAkq4Xo91pl-6exzLB4Q_sBd4SAs", // كما هو، إلا إذا غيّرتِ شيت الطالبات
  ROSTER_GID: "0", // رقم تبويب شيت الطالبات (0 = أول تبويب)
  SCRIPT_URL: "https://script.google.com/macros/s/XXXXXXXXXXXX/exec", // الصقي رابط الخطوة 3
  SHARED_TOKEN: "نفس-الكلمة-السرية-من-الخطوة-2",
  SHEET_VIEW_URL: "https://docs.google.com/spreadsheets/d/.../edit" // رابط شيت "قاعدة استئذان الطالبات" نفسه
};
```

### 7. رفع الصفحة على GitHub وعرضها (GitHub Pages)

لا حاجة لأي برنامج إضافي أو أوامر طرفية — كل الخطوات من موقع GitHub مباشرة
عبر المتصفح. **يُرفع فقط ملف `index.html`** (ملف `Code.gs` لا يُرفع إلى
GitHub إطلاقاً — مكانه فقط داخل محرر Apps Script، وملف `README.md` اختياري
رفعه للتوثيق فقط).

1. **أنشئي حساباً على GitHub** إن لم يكن لديك واحد: [github.com](https://github.com) ← Sign up.
2. **أنشئي مستودعاً (Repository) جديداً**:
   - من أعلى يمين الصفحة اضغطي **+** ← **New repository**.
   - اكتبي اسماً (مثلاً `istithan-form`)، واتركي باقي الخيارات كما هي.
   - اضغطي **Create repository**.
3. **ارفعي ملف `index.html`**:
   - داخل صفحة المستودع الجديد، اضغطي **Add file ← Upload files**.
   - اسحبي ملف `index.html` (بعد تعديل إعدادات `CONFIG` فيه كما في الخطوة 6)
     إلى الصفحة، أو اضغطي **choose your files** واختاريه.
   - مرّري للأسفل واضغطي **Commit changes**.
4. **فعّلي GitHub Pages**:
   - من أعلى صفحة المستودع اضغطي تبويب **Settings**.
   - من القائمة الجانبية اضغطي **Pages**.
   - تحت **Build and deployment ← Branch**، اختاري الفرع **main** (أو
     **master**) والمجلد **/ (root)**، ثم اضغطي **Save**.
5. **انتظري دقيقة أو دقيقتين**، ثم أعيدي فتح صفحة **Settings ← Pages** —
   سيظهر أعلاها رابط أخضر بالشكل:
   `https://<اسم-حسابك>.github.io/istithan-form/`
   هذا هو رابط الاستمارة الجاهزة، افتحيه من المتصفح (على الهاتف أو
   الحاسوب) واحفظيه كاختصار على الشاشة الرئيسية لسهولة الوصول.
6. **لتحديث الصفحة لاحقاً** (بعد أي تعديل تطلبينه مني على `index.html`):
   من داخل المستودع افتحي `index.html` ← أيقونة القلم (✏️ Edit) ← الصقي
   المحتوى الجديد ← **Commit changes**. يتحدّث الموقع المنشور تلقائياً خلال
   دقيقة تقريباً، بنفس الرابط دون تغيير.

> **بخصوص الخصوصية**: اجعلي المستودع **Private** إن كان ذلك متاحاً لحسابك
> (GitHub يسمح بمستودعات خاصة مجاناً)، لكن تنبّهي أن **GitHub Pages نفسها
> تبقى صفحة عامة الوصول عبر رابطها** حتى لو كان المستودع خاصاً، إلا إذا كان
> حسابك ضمن خطة GitHub Enterprise التي تدعم "Private Pages". لذلك الحماية
> الحقيقية هنا هي عدم مشاركة رابط الصفحة إلا مع من تثقين بهم، كما هو موضّح
> في قسم الخصوصية أدناه.

## تنبيه مهم بخصوص الخصوصية

هذه الصفحة ستكون **علنية الوصول** على الإنترنت (أي شخص يملك الرابط يفتحها)،
ورابط Apps Script والكلمة السرية موجودان داخل كود الصفحة نفسه الذي يراه أي
زائر (عبر "عرض مصدر الصفحة"). هذا يعني أن الحماية هنا **أضعف بكثير** من نسخة
Claude الأصلية، التي كانت تتطلب تسجيل دخولك وتُخفي البيانات عن غير المصرح
لهم. بما أن الاستمارة تحفظ بيانات حساسة (أرقام بطاقات شخصية، أرقام هواتف،
أسماء طالبات قاصرات)، يُنصح بشدة بما يلي:
- لا تنشري رابط الصفحة في مكان عام، واكتفي بمشاركته مع من تثقين بهم فقط
  (المنسقات المعنيات).
- اعتبري هذا الحل حلاً عملياً مؤقتاً وليس حلاً أمنياً كاملاً لبيانات حساسة.
- إن احتجتِ حماية أقوى (تسجيل دخول حقيقي، صلاحيات متعددة المستخدمين)،
  فهذا يتطلب تطويراً إضافياً خارج نطاق صفحة GitHub الثابتة.
- ميزة قراءة البطاقة التلقائية (OCR) تضيف نقطة إضافية: الصورة تُرفع مؤقتاً
  (ثوانٍ معدودة) إلى حساب جوجل درايف الذي تملكين منه الاستمارة، لتحويلها
  آلياً إلى مستند قابل للقراءة، ثم تُحذف الصورة والمستند الناتج فوراً. هذا
  أقل خصوصية من نسخة Claude الأصلية (حيث لا تغادر الصورة متصفح الزائرة
  إطلاقاً)، لكنه يبقى ضمن حسابك الخاص ولا يُرسل لأي جهة خارجية ثالثة.

## مشاكل شائعة عند تفعيل قراءة البطاقة

| الرسالة | السبب المحتمل والحل |
|---|---|
| "تعذّرت خدمة القراءة — تأكّدي من تفعيل خدمة Drive API" | لم تُفعَّل خدمة Drive API في خطوة 3، أو لم يُنشر إصدار جديد (Version: New version) بعد تفعيلها. |
| "رمز الدخول غير صحيح" | قيمة `SHARED_TOKEN` في `index.html` لا تطابق `Code.gs` حرفياً. |
| "تعذّرت قراءة أي نص من الصورة" | الصورة غير واضحة أو مُعتمة — أعيدي المحاولة بإضاءة أفضل وتقريب البطاقة. |
| لا شيء يحدث عند الضغط على زر المسح | تأكّدي أن `CONFIG.SCRIPT_URL` في `index.html` مُعدَّل فعلياً ولا يبدأ بـ `PASTE_`. |

## الملفات المرفقة
- `index.html` — الصفحة نفسها (هذا ما يُرفع على GitHub).
- `Code.gs` — الكود الذي يُلصق داخل Apps Script (لا يُرفع على GitHub).
- `README.md` — هذا الملف.
